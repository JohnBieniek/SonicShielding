Welcome to SonicShielding

To keep the SonicShielding toolbar button handy, pin the extension:

  1. Click the Extensions (puzzle) icon in the toolbar.
  2. Find SonicShielding in the list.
  3. Click the pin icon to keep it visible in the toolbar.

If you're using Brave, the same Extensions menu has a pin for each extension.

Pinning the icon makes it easy to protect tabs and see the ON badge.
