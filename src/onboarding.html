Sonic Shielding
Softer sound where you need it.
One quick setup step

Keep protection within reach.

Pin Sonic Shielding so you can protect the current tab whenever sound gets uncomfortable.

  1. 1Open the Extensions menu using the puzzle-piece button.
  2. 2Find Sonic Shielding in the list.
  3. 3Select the pin beside it to keep the blue shield visible.

How to use Sonic Shielding

Set your comfort profile

Choose Low, Balanced, or Strong dynamic protection and set a sudden-sound limit. Balanced preserves speech by default; optional permanent comfort EQ controls are available under Advanced settings.

Open comfort profile →

Turn it on for each tab

Open the pinned shield while viewing a tab and select Protect this tab. You must enable Sonic Shielding separately on every tab you want protected. Red means off; blue means protection is active.

These steps work in both Brave and Chrome. You can unpin the extension at any time.
